# Personal Project Conventions

## Context

These are personal/hobby projects. No corporate tooling, no internal services, no customer-facing obligations.

## Conventions

- **Git hosting**: GitHub. Use `gh` CLI for PRs and issues.
- **Cost awareness**: Be mindful of cloud costs. Prefer free tiers and local development.
- **Audience**: Yourself (future you), learning community, or OSS contributors.
- **Pace**: Long-lived projects. No sprint deadlines. Quality over speed.
- **No internal tools**: No organization-specific MCP servers, no internal search tools, no Slack notifications.
- **Task runners**: Prefer `just` or `mise`. Use what the project already has.

## What "done" means

- Code works locally
- Tests pass (if they exist)
- Committed with a meaningful message
- Pushed to GitHub (if remote exists)

No Slack notification. No issue filing unless you want to track it.
